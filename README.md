# WandoReserve.com — static reference site v3
Deploy the contents of this directory to your web root. No build, database, accounts or server-side scripts are needed. All artwork and six supplied PDFs are local. The site deliberately has no calendar, announcement feed or public violation gallery. Official notices remain with management.

For occasional updates, edit the relevant HTML page; shared portal and legal name are in assets/js/site-data.js, navigation/footer in assets/js/app.js, styling in assets/css/style.css. Keep updates.html as a stable link to Meetings & Notices. Verify local phone numbers, document currency, recorded easement dimensions and any adopted amendments before publication and during periodic review. No new rental or covenant restrictions are represented as adopted.
